# Review gates

Only explicit `--interactive` pauses after research, plan, implementation and testing.
Present the concrete result at each checkpoint. Reuse authorization in every other mode.

All modes require acceptance review, affected contract/regression inspection and relevant
checks (report tests unverified under `--no-test`). Repair implementation-caused regressions
within scope; a product-contract reversal or unauthorized destructive action needs a decision.
With `--advice`, obtain failed-verification counsel before any repair or re-diagnosis.

Finalize by reconciling the existing plan, assessing docs impact, updating available tracking,
and applying the SKILL.md journal preference contract. Git mutations require applicable
user authorization; finalization does not itself authorize a commit or publication.
